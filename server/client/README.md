# Interface Home Application

React, TypeScript et Vite. Depuis ce dossier :

```bash
npm ci
npm run dev
npm run check
npm test
npm run build
```

Le proxy de développement dans `vite.config.ts` transmet `/api` au serveur local sur le port 4000.
Les paramètres de connexion et les commandes mobiles sont décrits dans le [README principal](../../README.md).
